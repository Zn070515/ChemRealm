# Apparatus catalog QA

Before a specification is released:

1. validate the typed catalog and compare specification IDs with
   `manifest.json`;
2. confirm dimensions and graduations against the cited claim scope;
3. inspect every detachable part and both sides of each declared port;
4. confirm `V(h)`/`h(V)` is supplied separately for any object used for a
   liquid-level observation;
5. capture the object in the common orthographic light/material family;
6. test empty, filled, connected and disconnected states where declared;
7. review accessibility labels, scale legibility and contrast at the four M6
   viewports.

The master is a reviewable construction sheet, not a runtime source of
scientific values. Runtime rendering must consume frozen state and profile
data through the Representation Engine contracts.
