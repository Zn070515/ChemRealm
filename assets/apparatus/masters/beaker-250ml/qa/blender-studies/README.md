# Blender controlled-study evidence

This directory is generated by the additive M6 visual-study job. It is review
evidence, not an admitted asset package and not a Gold Master.

The study root is keyed by the manifest study ID. Each round contains candidate
`.blend` files, render metadata, render outputs, and a contact sheet. The `ab`
directory compares the provisional Form F03 study against the rejected SVG
under matched review views.

The candidate selection fields in `review.md` remain
`pending-owner-review` until the owner explicitly chooses a form, glass
treatment, and lighting rig.
