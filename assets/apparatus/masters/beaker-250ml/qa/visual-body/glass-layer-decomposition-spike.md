# Glass-layer decomposition spike

Status: prototype evidence only; not Gold Master admission.

## Fixture

The spike uses the checked-in `body.png` and the corrected cavity-derived
`liquid-mask.svg`. The liquid is a deliberately exaggerated deep-blue visual
placeholder. It is not a scientific volume, a `VolumeProfileSnapshot`, or a
chemistry state.

## Variants

| Variant | Composition | Observation |
|---|---|---|
| A | liquid behind the single body PNG | The near-opaque body suppresses most liquid visibility. |
| B | liquid above the single body PNG | The liquid obscures the authored glass response and base detail. |
| C | opacity/blend compromise | Neither the glass response nor liquid appearance is authoritative. |

The light/dark contact sheet is generated by:

```text
pnpm preview:beaker-glass-layer-spike
```

Output: `glass-layer-decomposition-spike-light-dark.png`.

The follow-up geometry study is generated by:

```text
pnpm generate:beaker-liquid-visual-geometry-spike
pnpm preview:beaker-liquid-geometry-spike
```

It uses a hand-authored cavity outline and perspective-ellipse surface paths
for 25/100/200 mL visual fixtures. The heights and blue appearance remain
prototype-only; production must receive a validated `h(V)` result and an
approved Observable optical appearance.

## Decision

The single authored body is suitable as a visual-body candidate, but it is not
yet a production liquid-compositing contract. A future assetization step must
evaluate a real `glass-back → liquid/effects → glass-front` decomposition (or
an equivalently validated compositing representation) before dynamic liquid is
wired into production.

This spike does not change the scientific owner of liquid height and does not
promote the asset beyond `visual-body-candidate` / `not-gold-master`.
