## What changed

`packages/schema` went from empty to the complete contract surface: quantity
types and the single conversion module; zod schemas for every persisted, runtime
and content shape; JSON Schema emission with a CI drift check; a migration
registry; and the Python side that consumes the emitted artifacts.

The remediation then changed four things about *what those contracts mean*, which
is why it needed an owner ruling rather than a patch:

1. **What the world conserves.** `CanonicalContents` stored
   `materials: { materialId, amount }[]`. A material is a reagent recipe, and a
   recipe is not a conserved physical quantity. Now `componentAmounts:
   { componentId, amount }[]`, with four levels kept distinct — authored recipe,
   resolved recipe, conserved component inventory, equilibrium-derived species.
2. **Where the types stop being types.** One `z.infer` type served as both the
   runtime model and the wire format, so the entire opaque/branded quantity
   apparatus flattened back to `number` at the most important boundary in the
   project. Domain interfaces and serialized DTOs are now separate, joined by
   parse functions that go through the constructors.
3. **Unknown keys, on both sides of the boundary.** TypeScript stripped them;
   the emitted artifact told Python to reject them.
4. **The export bundle's learner-evidence field.** It accepted any key at all.

## Scientific evidence

M1 establishes the **representation** of quantities, not any chemical model. The
science lands at M4; this milestone is what makes a wrong quantity a compile
error before it can become a wrong number.

What is already load-bearing:

- **One conversion module, no stray factors.** Every factor lives in
  `quantity.ts` / `units.ts`; no `* 1000` appears elsewhere in the repository.
- **The standard-state distinction is carried by types.** `ReducedMolality` and
  `MolPerKilogram` are numerically identical at `m° = 1 mol/kg` and must never be
  interchangeable; `units.test.ts` states this as a *negative* result rather than
  pretending a runtime test can catch it.
- **Molality ↔ molarity is explicit and sourced.** `molalityToMolarity` requires
  a solution density and a molar mass; the density is a required scenario input
  (AC-S15), never an invented default. The 0.1000 mol/L HCl case reproduces
  0.100165 mol/kg.
- **Dimensionless quantities are representable.** ISO 80000's unit one (`"1"`)
  is the canonical unit of the `dimensionless` dimension, so activity, `γ`, mole
  fraction, reduced molality and reduced ionic strength serialize as
  `{ value, unit: "1" }` — and `{"value": 1e-9, "unit": "mol/kg"}` for a
  `Ka` is now a rejection rather than an untraceable mix-up.

## Known limitations

Explicit, because a limitation not written down is a claim that it does not exist.

1. **The World Runtime has no domain types yet.** Item 2 typed the *Scientific*
   API. `WorldState`, `Command` and the events remain DTO-shaped, and the reducer
   is where they should be parsed into typed values — at M2. Until then, a bare
   `number` can still be written where a world quantity is meant.
2. **Two `parameters` bags are raw `Record<string, number>`** — on `Provenance`
   and `SolverConfig`. They are replay records pinned by value, but a
   *conditional* `Kw` stored there would be undetectable. Declaring each
   constant's kind belongs to the model descriptor at M4. Recorded at the
   definitions.
3. **`IndicatorState.protonationRatio` is a bare number, deliberately.**
   `SPEC-0001` AC-V9 requires it: "`packages/render` receives a number and
   computes no `Ka`". This is the one place where a plain number at the boundary
   is the specification rather than a shortcut.
4. **`SolveResult`'s `NOT_CONVERGED.residual` is a bare number.** A convergence
   diagnostic, bounded by the iteration scheme, never stored.
5. **`log10ActivityCoefficient` uses the native `Math.log10`.** `ADR-0007`
   requires the replay path to use `detLog10`, which M4 creates. Nothing on the
   replay path calls it yet, and the obligation is written at the call site.
6. **`Apparatus.state` is an open `Record<string, unknown>`** — a deliberate
   extension point, because the per-kind shape belongs to the apparatus asset
   contract at M6. Recorded as a decision at its definition, not left to look
   like an oversight.
7. **No `content/` scenario file is committed.** The scenario schema is tested
   against in-test fixtures; M7 authors the first real content file.
8. **The whole contract surface ships to the browser** — 324 kB uncompressed.
   A subpath-export decision is needed before the bundle matters, which is not
   yet.
9. **`tools/check_acceptance_coverage.py` checks the PLAN, not the code.** It
   proves every milestone's claims are evidenced *in the plan*; it cannot know
   whether the named test exists or asserts what the row says. That gap is why
   this packet's matrix names files and test names rather than trusting the
   checker alone.
