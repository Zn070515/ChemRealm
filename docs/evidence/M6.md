# M6 Implementation Evidence

**Status:** **S2 — implementation baseline; visual-system gate NO-GO; owner acceptance pending.**

M6 is authorized by [`M6-entry.md`](M6-entry.md). This packet records the
first technical apparatus implementation slice and its limits. The slice is
informed by the local NOBOOK/Zhejiang research, but the current visual result
is not accepted as final-quality. The governing visual standard is
[`m6-art-direction.md`](../visual/m6-art-direction.md), and the remediation
specification is
[`2026-09-15-m6-visual-asset-system-redesign.md`](../superpowers/specs/2026-09-15-m6-visual-asset-system-redesign.md).
This packet does not claim M6 S3 or authorize M7.

## Implemented path

```text
committed WorldState
  → ScientificFrame / ObservableModel
  → renderer-neutral RenderState
  → @chemrealm/render/pixi
  → self-hosted Pixi canvas

the same RenderState
  → DOM inspection/readout companion
```

The Pixi adapter has no Sci or World imports. It does not solve chemistry,
choose an equilibrium direction, resolve mutable geometry references, or
invent an optical tint. The default production fixture remains an optical
coverage refusal, and the canvas uses a neutral liquid material for that
refusal while the DOM keeps the reason visible.

The visual contract now separates an orthographic-camera `experiment-world`
from a strict frontal `measurement` presentation. Catalog, inspector and
construction previews may use bounded 2.5D only when labelled
`non-measurement`. The first owner-reviewed Gold Master set is acid/alkali
burettes, 100/250/1000 mL beakers and 100/250/500 mL Erlenmeyer flasks; the
remaining catalog families are not evidence that this first set has passed.
Master/scene/preview/thumbnail LODs must share semantic identity, and every
Gold Master requires both dark-neutral and light-neutral captures.
