## Implemented path

```text
committed WorldState
  → ScientificFrame / ObservableModel
  → renderer-neutral RenderState
  → @chemrealm/render/pixi
  → self-hosted Pixi canvas

the same RenderState
  → DOM inspection/readout companion
```

The Pixi adapter has no Sci or World imports. It does not solve chemistry,
choose an equilibrium direction, resolve mutable geometry references, or
invent an optical tint. The default production fixture remains an optical
coverage refusal, and the canvas uses a neutral liquid material for that
refusal while the DOM keeps the reason visible.

The visual contract now separates an orthographic-camera `experiment-world`
from a strict frontal `measurement` presentation. Catalog, inspector and
construction previews may use bounded 2.5D only when labelled
`non-measurement`. The first Gold Master candidate set is one 25 mL acid
burette, one 50 mL alkali burette, one 250 mL beaker and one 250 mL Erlenmeyer
flask; the remaining catalog families are planned/reference-only and are not
evidence that this set has passed.
Master/scene/preview/thumbnail LODs must share semantic identity, and every
Gold Master requires both dark-neutral and light-neutral captures.

The current Gold Master candidate has been structurally reworked around
family-owned anatomy and explicit landmarks. Acid and alkali burettes no longer
share a fictitious actuator/base layer: the acid variant declares a PTFE
stopcock and rotary key, while the alkali variant declares a lower connector,
rubber tube, glass bead and pinch region. Beaker spouts are rim-continuous and
flasks use curved shoulder/neck geometry. Family-specific material profiles,
master-without-shadow policy, deterministic LOD detail reduction and
master-derived comparison sheets are package-tested. These are implementation
evidence only; they do not replace owner visual captures.

The candidate package is deliberately separate from the legacy M5 first-slice
Pixi fixture. The current browser composition still consumes
`TITRATION_BENCH_ASSET` and its legacy scene drawing; that capture is regression
evidence for the existing runtime path, not visual evidence that the new Gold
Master candidate has been integrated or owner-approved. Production composition
integration remains an explicit M6/M7 boundary item.
