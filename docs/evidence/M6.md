# M6 Implementation Evidence

**Status:** **S2 — implementation in progress; visual owner acceptance pending.**

M6 is authorized by [`M6-entry.md`](M6-entry.md). This packet records the
first final-quality apparatus implementation slice informed by the local
NOBOOK research and the M6 web evidence brief. It does not claim M6 S3 or
authorize M7.

## Implemented path

```text
committed WorldState
  → ScientificFrame / ObservableModel
  → renderer-neutral RenderState
  → @chemrealm/render/pixi
  → self-hosted Pixi canvas

the same RenderState
  → DOM inspection/readout companion
```

The Pixi adapter has no Sci or World imports. It does not solve chemistry,
choose an equilibrium direction, resolve mutable geometry references, or
invent an optical tint. The default production fixture remains an optical
coverage refusal, and the canvas uses a neutral liquid material for that
refusal while the DOM keeps the reason visible.

## Reproduction

```text
pnpm generate:versions
pnpm typecheck
pnpm typecheck:tests
pnpm test
pnpm build
pnpm depcruise
pnpm guards
pnpm verify:m6-renderer
pnpm verify:m6-entry
pnpm test:browser
pnpm artifacts
git diff --check
```

For candidate captures, set `M6_CAPTURE=1` and run the capture command in
[`review-m6.md`](../visual/review-m6.md). The capture files are evidence
inputs, not owner-approved baselines.
