## Scope

The World Runtime now owns typed immutable state, command validation, an
append-only event log, deterministic replay, snapshot caches, explicit replay
identity hashing, and first-class branch creation. It imports only
`@chemrealm/schema`; it does not import the Scientific Reality Core.

## Runtime contract checks

- `WorldCreated` is required at sequence zero; all later events must be the
  next sequence boundary.
- Every event volume is normalized to canonical litres at the command/log
  boundary and canonicalized again at the reducer input boundary.
- Canonical contents contain only water mass, liquid volume, and sorted
  component amounts. State and snapshots are deeply frozen.
- State hashes exclude the cursor and use an explicit replay-identity
  projection: solver configuration, genesis snapshot, provenance, structure,
  lineage, and IDs are exact; only canonical independent contents are
  quantized. Science hashes are derived verification artifacts and are not
  stored in world state.
- The SHA-256 implementation is synchronous and dependency-free, so the World
  Runtime has no Node-only hashing dependency in a browser-local product.
- Internal branches store a shared immutable prefix plus an owned suffix;
  parent logs and state graphs are never mutated. Flattening is an explicit
  portability/export boundary reserved for M8.

## Known limitations carried forward

- Snapshot acceleration validates cache structure, state hash, sequence, solver
  configuration, world identity, genesis content hash, and exact event-prefix
  hash. Deleting every snapshot always falls back to the complete event fold;
  persistent snapshot storage is M8.
- The v0 resolver's material basis boundary is the accepted ADR-0010 domain;
  the reducer consumes its resolved inventory and performs no chemistry.
