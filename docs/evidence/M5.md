## Boundary decisions

- `ScientificProjection` owns the molality-to-molarity presentation boundary;
  its input contains only the physical solution volume required for that
  conversion.
- The pH-volume curve is owned by ObservableModel and consumes an ordered
  sequence of already-computed values. It does not solve chemistry.
- Indicator colour is an empirical ratio-to-token interpolation. The
  Scientific Core owns indicator equilibrium and `protonationRatio`.
- M5 has no animation clock. Clock ownership remains a renderer decision for
  M6 and cannot enter world state or replay identity.
- `@chemrealm/render` may import schema contracts only; it does not import
  `@chemrealm/sci`, `@chemrealm/world`, `@chemrealm/ace`, DOM, or PixiJS.

## Known limitations and next gate

- This is an S2 handoff, not a product-ready visual milestone.
- AC-V3 needs a dedicated render source/token guard before S3.
- AC-V10 and AC-V11 need an inspection presentation and browser assertions;
  their scientific inputs are already present in the ObservableModel.
- M6 owns apparatus interaction geometry, semantic asset contracts, PixiJS,
  animation-clock ownership, screenshots, and visual review.
