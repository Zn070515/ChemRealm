## Current composition and optical boundary

The production path is:

```text
authored Scenario
  → WorldCreated / replayed WorldState
  → exact Scientific Core frame
  → ScientificState indicator chemical observation
  → Representation Engine optical observation
  → ObservableModel / RenderState
  → local DOM inspection surface
```

The default v0 fixture uses the one admitted ordinary-aqueous
phenolphthalein profile and renders `OPTICAL_MODEL_OK` only inside its declared
coverage, with dose, concentration, path, profile identity/hash, tint
strength, and transmittance samples exposed in the DOM. Unsupported forms,
conditions, or missing historical data still render an explicit tagged
refusal with no indicator tint. Strong-acid phenolphthalein orange remains
documented and refusal-only.

## Boundary decisions

- The Scientific Core owns chemical-form coverage and returns either covered
  form fractions or an explicit refusal. The Representation Engine owns only
  the Beer–Lambert/colourimetry transform after all frozen inputs are present.
- No endpoint RGB palette, pH threshold, `Ka`, activity, or protonation ratio
  is used as a colour fallback. A refusal has no swatch/tint.
- `ScientificFrame.physical` owns the committed liquid volume, temperature,
  solvent, optical path, and profile snapshots. ObservableModel consumes this
  single physical context and does not accept a second executable profile or
  liquid volume.
- Optical profile/path payloads are content-addressed and revalidated before
  executable interpolation or optical calculation. A matching hash string by
  itself is insufficient.
- `sourceStateHash` remains the World Runtime replay-equivalence identity; it
  is not an exact snapshot checksum and is not a cryptographic signature.
- Readout strings and precision policy belong to ObservableModel; the DOM is an
  inspection adapter and the final visual renderer remains M6-owned.
- `@chemrealm/render` imports schema contracts only and has no dependency on
  `@chemrealm/sci`, `@chemrealm/world`, `@chemrealm/ace`, DOM, or PixiJS.
