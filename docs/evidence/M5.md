## Boundary decisions

- `ScientificProjection` owns the molality-to-molarity presentation boundary;
  its input contains the physical solution volume required for that conversion
  and the authoritative source-state identity used to bind the result.
- The pH-volume curve is owned by ObservableModel and consumes an ordered
  sequence of already-computed values. It does not solve chemistry.
- Indicator colour is an empirical ratio-to-token interpolation selected by
  indicator identity. The Scientific Core owns indicator equilibrium and
  `protonationRatio`; the render catalogue owns only presentation palettes.
- Projection identity is created by `projectScientificFrame(...)` in the
  Scientific Core; render consumes the structural frame and must not invent a
  second projection identity.
- Readout strings and precision policy belong to the ObservableModel boundary;
  a future DOM/Pixi Renderer owns actual text drawing.
- The M5 contract guard checks that this child specification does not weaken
  canonical AC-V3/AC-V4/AC-V6/AC-V8 wording or overstate partial evidence.
- M5 has no animation clock. Clock ownership remains a renderer decision for
  M6 and cannot enter world state or replay identity.
- `@chemrealm/render` may import schema contracts only; it does not import
  `@chemrealm/sci`, `@chemrealm/world`, `@chemrealm/ace`, DOM, or PixiJS.
