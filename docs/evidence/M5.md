## Boundary decisions

- `ScientificProjection` owns the molality-to-molarity presentation boundary;
  its input contains the physical solution volume required for that conversion
  and the authoritative source-state identity used to bind the result.
- The pH-volume curve is owned by ObservableModel and consumes an ordered
  sequence of already-computed values. It does not solve chemistry.
- Interim indicator output is an empirical ratio-to-`IndicatorTint`
  interpolation selected by indicator identity. `strength` is a bounded
  qualitative presentation interpolation, never opacity, concentration,
  absorbance, or a Beer–Lambert result. The Scientific Core owns indicator
  equilibrium and `protonationRatio`; the render catalogue owns only the
  reviewed presentation palette. Quantitative optical observation is a later
  refusal-first Representation Engine boundary.
- Projection identity is created by `projectScientificFrame(...)` in the
  Scientific Core; render consumes the structural frame and must not invent a
  second projection identity.
- `ScientificFrame.physical.liquidVolume` is the only volume used by the
  projection and liquid-level observable. Its `volumeProfileHash` must match
  the replay-frozen profile snapshot supplied to Observable. Observable
  reconstructs the executable interpolation adapter internally; callers cannot
  supply a function-valued profile with a self-reported matching hash.
- The profile hash is a content-address check, not a label comparison:
  `parseVolumeProfileSnapshot` recomputes the canonical hash over the payload
  excluding `profileHash` before Observable reconstructs executable geometry.
- Genesis vessels persist the serializable `VolumeProfileSnapshot`; legacy
  geometry-only worlds require an explicit v3→v4 profile resolver before
  replay.
- `sourceStateHash` means the quantized World Runtime replay-equivalence hash;
  exact snapshot cache integrity is a separate checksum and is not reused as
  frame identity.
- Readout strings and precision policy belong to the ObservableModel boundary;
  a future DOM/Pixi Renderer owns actual text drawing.
- The M5 contract guard checks that this child specification does not weaken
  canonical AC-V3/AC-V4/AC-V6/AC-V8 wording or overstate partial evidence.
- M5 has no animation clock. Clock ownership remains a renderer decision for
  M6 and cannot enter world state or replay identity.
- `@chemrealm/render` may import schema contracts only; it does not import
  `@chemrealm/sci`, `@chemrealm/world`, `@chemrealm/ace`, DOM, or PixiJS.
