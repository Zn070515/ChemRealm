## Toolchain prerequisite

The PHREEQC release, extracted `phreeqc.dat` checksum, and CI-built executable
identity metadata are recorded in
[`tools/oracle/phreeqc/manifest.json`](../../tools/oracle/phreeqc/manifest.json).
The official USGS download page lists the pinned `3.8.6-17100` source archive
and batch distributions. `install_ci.sh` provides the checked-in Linux build
path and writes `toolchain.json`; `run_batch.py` verifies that metadata and the
database before invoking the CLI. The actual local run is recorded in
[`M4-reference-report.json`](M4-reference-report.json); CI runs the same
installation and validation command as a hard gate.

The cross-engine report uses `REF-9` at `0.14 mol/kg` NaOH as the representative
post-equivalence point. This is a declared fixture choice within the `±0.02`
pH comparison envelope; the report does not claim an untested `0.15 mol/kg`
post-equivalence point.
