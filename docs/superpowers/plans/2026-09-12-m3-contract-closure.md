# M3 Contract Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the M3 solver contract gaps so asynchronous science orchestration, exact solver identity, typed solute semantics, out-of-domain diagnostics, and world-creation rejection are verifiable before M4.

**Architecture:** Keep `packages/world` a synchronous, deterministic event reducer that never invokes a `SolverAdapter`. Keep asynchronous solving at the composition boundary, where a resolver produces the complete `SolverConfig` frozen into `WorldCreated` and later orchestration awaits `solve`. Make the v0 adapter one-model/one-config identity, and make the scientific request/result unions reject semantically contradictory states at the schema boundary.

**Tech Stack:** TypeScript 5.9, Zod, Vitest, pnpm workspaces, React/Vite composition root, generated JSON Schema artifacts, Markdown ADR/SPEC/evidence documents.

**Spec:** `docs/specs/SPEC-0001-world-foundation-acid-base-titration.md`, `docs/plans/PLAN-0001-world-foundation-acid-base-titration.md`, `docs/adr/0003-scientific-solver-adapter-boundary.md`, and the M3 review findings supplied in the task.

## Global Constraints

- The World Runtime remains synchronous and deterministic; it must not import `@chemrealm/sci` or call/await a solver.
- `SolverAdapter.solve(request)` remains `Promise<SolveResult>` from the start, including for the stub adapter.
- v0 uses one adapter = one model = one exact solver config; adapter/model/config `id` and `version` must agree.
- `MODEL_OUT_OF_DOMAIN` always includes a machine-readable `nearestSupported` descriptor.
- A solute is either `mode: "fully-dissociated"` with no `ka`, or `mode: "monoprotic-equilibrium"` with a positive `ka`.
- Incompatible model requirements reject genesis before a `WorldCreated` event is emitted; no fallback or silent version substitution is allowed.
- Existing event sourcing, replay, branch, quantity, privacy, dependency, and artifact contracts remain intact.
- All new behavior is developed test-first: write a failing test, run the targeted test to observe the expected failure, implement the minimum change, then rerun targeted and regression tests.
- Work directly in the current shared working tree; each completed implementation/documentation round is verified, committed, and pushed to the configured upstream branch without creating a pull request.

## File Map

- `packages/schema/src/scientific.ts` owns wire DTO schemas, DTO types, and DTO-to-domain bridges for solute modes and solver results.
- `packages/sci/src/adapter.ts` and `packages/sci/src/stub.ts` own the one-model adapter/config interface and deterministic stub behavior.
- `packages/sci/src/registry.ts` owns exact adapter registration and resolution, including identity validation and complete `SolverConfig` output.
- `packages/sci/src/request.ts` owns runtime validation of the discriminated request union.
- `packages/world/src/reduce.ts` and `packages/world/src/reduce.test.ts` own the synchronous world transition boundary and its no-solver regression test.
- `packages/world/src/replay.ts` owns synchronous replay and a clearly documented science projection callback, not solver orchestration.
- `apps/web/src/world-creation.ts` and its test own the composition-level genesis builder that resolves requirements and emits no event on incompatibility.
- `apps/web/package.json` and `pnpm-lock.yaml` expose the composition root's workspace dependencies.
- `docs/specs/SPEC-0001-world-foundation-acid-base-titration.md`, `docs/plans/PLAN-0001-world-foundation-acid-base-titration.md`, `docs/adr/0003-scientific-solver-adapter-boundary.md`, and `docs/evidence/M3.md` describe the resulting contract and evidence without self-accepting owner review.
- `CLA.md`, `COMMERCIAL-LICENSING.md`, and `README.md` implement the selected licensing policy: paid educational institutions may use code where PolyForm permits it; separate licensing is required only for commercial code use outside that public permission; CC BY-NC-SA content remains separately governed.
- `packages/schema/json-schema/*.json` are regenerated by the existing emitter after schema changes and checked for drift.

## Final Stop/Go Gate

Go only if all of the following are reproducibly true:

- A world reducer call returns synchronously and has no solver callback seam.
- A compatible registry result includes the exact adapter/model/config identity that genesis persists.
- Contradictory solute modes and missing `nearestSupported` are rejected by schema/runtime tests.
- An incompatible scenario returns before any `WorldCreated` event exists.
- The generated schema artifact check is clean.
- CLA wording centralizes broad relicensing in the Project Owner and commercial policy matches the selected PolyForm boundary.
- M3 evidence is current, bounded, and does not claim owner verification prematurely.

If any P0/P1 remains or any verification command fails, do not describe M3 as complete; preserve the failing output and keep the branch at the current candidate gate.
