# Rejected visual patterns

This file records failure modes so that procedural convenience does not
silently become the M6 art standard.

## Current rejected SVG candidate

The existing `assets/apparatus/masters/beaker-250ml/master.svg` remains useful
as a structural and A/B fixture. It is not a Gold Master. The current review
identifies these risks:

- rectangular body proportions that read as a technical icon rather than an
  individually designed Griffin silhouette;
- spout geometry that is attached rather than continuously formed;
- uniform blue-green body treatment that substitutes color for glass structure;
- strong outline/highlight dependence that changes behavior with background;
- markings that compete with the vessel's form hierarchy;
- a single procedural visual language copied too early across an apparatus
  family.

## Rejection rule

A candidate remains rejected when it passes structural QA but fails the visual
reference review. Passing dimensions, object names, material assignment, and
render completion cannot promote prototype art.

## Study use

The Blender study must compare against this candidate under matched framing,
but it must not optimize by merely adding more outline, more saturation, or
more reflections. The goal is a better visual language, not a more decorated
technical icon.
