# Visual Reference Index

This directory contains two deliberately different kinds of reference.

## Scientific/physical references

These record source-backed apparatus observations and empirical optical
references. They do not authorize copying an external product's artwork,
branding, texture, or implementation.

- [Source register](sources.json)
- [250 mL Griffin beaker](beaker.md)
- [Glass language](glass.md)
- [Lighting and reflection cards](lighting.md)
- [Composition and review views](composition.md)
- [Rejected prototype patterns](rejects.md)

Every external source must be linked through `sources.json` with publisher,
access date, usage status, and the observations it supports. A linked image is
not a ChemRealm production asset. Unknown license status means description-only
reference; it must not be downloaded into the asset package.

## Existing indicator reference

The following artifacts remain the M5 contract artifact for identity-keyed
indicator colour presentation:

- Registry: [`indicator-palettes.json`](indicator-palettes.json)
- Labelled swatches: [`indicator-reference-swatches.svg`](indicator-reference-swatches.svg)
- M5 contract review: [`indicator-palette-review.md`](indicator-palette-review.md)

Indicator colours are empirical presentation approximations. They are not
equilibrium calculations, calibrated spectrophotometer measurements, or final
apparatus artwork. The Scientific Core supplies the protonation ratio; the
Observable boundary selects and interpolates the declared palette. M6 owns
concrete apparatus assets, final renderer realization, screenshots, and owner
visual review.

## Reading rule

The Bible uses these labels:

- `source-backed`: an externally documented physical or product observation;
- `visual-approximation`: an authored choice that improves legibility without
  claiming measurement;
- `ChemRealm-policy`: a project-level visual rule;
- `rejected`: a known failure mode that must not return through procedural
  convenience.
