# Empirical indicator palette references

This directory contains the M5 contract artifact for indicator colour
presentation. The registry and labelled SVG swatches make the qualitative
reference behind each identity-keyed palette inspectable and machine-checkable.

These colours are an empirical presentation approximation. They are not
equilibrium calculations, calibrated spectrophotometer measurements, or the
final apparatus artwork. The Scientific Core supplies the protonation ratio;
the Observable boundary selects and interpolates the declared palette. M6 owns
concrete apparatus assets, final renderer realization, screenshots, and owner
visual review.

- Registry: [`indicator-palettes.json`](indicator-palettes.json)
- Labelled swatches: [`indicator-reference-swatches.svg`](indicator-reference-swatches.svg)
- M5 contract review: [`indicator-palette-review.md`](indicator-palette-review.md)
